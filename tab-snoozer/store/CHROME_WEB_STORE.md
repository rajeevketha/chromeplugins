# Tab Snoozer — Chrome Web Store pack

Version: **1.8.1**

## Upload package

```bash
./build-store-zip.sh
```

Publishes to Files (`/opt/cursor/artifacts`):

| File | Use |
|---|---|
| `TabSnoozer-1.8.1-store.zip` | **Package** upload (manifest at zip root) |
| `TabSnoozer-store.zip` | Stable alias of the same build |
| `TabSnoozer-1.8.1-cws-assets.zip` | Listing copy, screenshots, promo, justifications |
