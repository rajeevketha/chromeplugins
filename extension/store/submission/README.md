# OrgKit Chrome Web Store submission pack (v1.6.6)

This folder is everything you need to submit OrgKit.

| Item | File |
|---|---|
| Upload zip | `../../OrgKit-1.6.6-store.zip` (also in Files: `OrgKit-1.6.6-store.zip`) |
| Checklist | `SUBMIT_CHECKLIST.md` |
| Listing copy | `LISTING_COPY.txt` |
| Permission justifications | `PERMISSION_JUSTIFICATIONS.txt` |
| Privacy questionnaire | `PRIVACY_QUESTIONNAIRE.txt` |
| Privacy page to host | `privacy.html` |
| Reviewer notes / proofs | `proofs/REVIEWER_NOTES.txt` |
| Screenshots 1280×800 | `screenshots/*-1280x800.png` |
| Screenshots 640×400 | `screenshots/*-640x400.png` |
| Promo tiles | `promo/` |
| Icons | `icons/icon-128.png` |

## Important

1. **Host `privacy.html` on public HTTPS** before submit (GitHub Pages recommended).
2. Screenshots here are **sanitized demo UI** (no real email/org IDs).
3. Upload only the **store zip** of the extension root — not this whole repo.

See `SUBMIT_CHECKLIST.md` for the click-by-click flow.
